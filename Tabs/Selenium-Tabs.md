# Selenium Tabs

## 1. Introduction

In Selenium WebDriver, a browser tab is represented by a **window handle**.

Selenium does not directly identify a tab by its visual tab name. Instead, each browser window or tab has a unique identifier called a **Window Handle**.

Commonly used methods:

```java
driver.getWindowHandle();
driver.getWindowHandles();
driver.switchTo().window(windowHandle);
```

---

# 2. Window Handle

A window handle is a unique `String` value assigned by the browser to a browser window or tab.

```java
String parentWindow = driver.getWindowHandle();

System.out.println(parentWindow);
```

Example output:

```text
CDwindow-1234567890ABCDEF
```

The actual value is generated by the browser and can be different every time.

---

# 3. getWindowHandle()

`getWindowHandle()` returns the handle of the **current browser window/tab**.

Syntax:

```java
String handle = driver.getWindowHandle();
```

Example:

```java
WebDriver driver = new ChromeDriver();

driver.get("https://example.com");

String currentWindow = driver.getWindowHandle();

System.out.println("Current Window: " + currentWindow);
```

---

# 4. getWindowHandles()

`getWindowHandles()` returns the handles of **all currently open browser windows/tabs**.

Return type:

```java
Set<String>
```

Example:

```java
Set<String> handles = driver.getWindowHandles();

for (String handle : handles) {
    System.out.println(handle);
}
```

Example output:

```text
CDwindow-111111
CDwindow-222222
CDwindow-333333
```

---

# 5. getWindowHandle() vs getWindowHandles()

| Method               | Returns       | Purpose               |
| -------------------- | ------------- | --------------------- |
| `getWindowHandle()`  | `String`      | Current window/tab    |
| `getWindowHandles()` | `Set<String>` | All open windows/tabs |

Example:

```java
String parent = driver.getWindowHandle();

Set<String> allWindows = driver.getWindowHandles();
```

---

# 6. Switching to Another Tab

Use:

```java
driver.switchTo().window(windowHandle);
```

Example:

```java
for (String handle : driver.getWindowHandles()) {

    if (!handle.equals(parentWindow)) {
        driver.switchTo().window(handle);
    }
}
```

---

# 7. Parent and Child Tab

Suppose:

```text
Parent Tab
    |
    +---- Child Tab
```

Store the parent handle before opening the child tab.

```java
String parentWindow = driver.getWindowHandle();
```

Then obtain all handles:

```java
Set<String> windows = driver.getWindowHandles();
```

Switch to the child:

```java
for (String window : windows) {

    if (!window.equals(parentWindow)) {
        driver.switchTo().window(window);
        break;
    }
}
```

---

# 8. Complete Parent → Child Example

```java
import java.util.Set;

import org.openqa.selenium.By;
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.chrome.ChromeDriver;

public class TabExample {

    public static void main(String[] args) {

        WebDriver driver = new ChromeDriver();

        driver.manage().window().maximize();

        driver.get("https://example.com");

        String parentWindow = driver.getWindowHandle();

        driver.findElement(By.linkText("Open New Tab")).click();

        Set<String> allWindows = driver.getWindowHandles();

        for (String window : allWindows) {

            if (!window.equals(parentWindow)) {

                driver.switchTo().window(window);

                System.out.println("Child Tab Title: "
                        + driver.getTitle());

                break;
            }
        }

        driver.quit();
    }
}
```

# 9. Switching Back to Parent Tab


```java

}

// Return to parent

```

# 13. Identifying a Tab by Title

Instead of relying on the position of the tab, you can switch based on the title.

```java
Set<String> windows = driver.getWindowHandles();

for (String window : windows) {

    driver.switchTo().window(window);

    if (driver.getTitle().equals("Expected Title")) {
        break;
    }
}
```

This is generally safer than:

```java
driver.switchTo().window(windows.get(1));
```

because the order of handles should not be relied upon.

---

# 14. Identifying a Tab by URL

You can also identify a tab using its URL.

```java
Set<String> windows = driver.getWindowHandles();

for (String window : windows) {

    driver.switchTo().window(window);

    if (driver.getCurrentUrl().contains("example")) {
        break;
    }
}
```

# 18. TAB vs WINDOW

```java
driver.switchTo().newWindow(WindowType.TAB);
```

opens a new browser tab.

```java
driver.switchTo().newWindow(WindowType.WINDOW);
```

opens a new browser window.

# 19. Complete Selenium 4 New Tab Example

```java
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.chrome.ChromeDriver;
import org.openqa.selenium.WindowType;

public class NewTabExample {

    public static void main(String[] args) {

        WebDriver driver = new ChromeDriver();

        driver.manage().window().maximize();

        driver.get("https://example.com");

        String parentWindow = driver.getWindowHandle();

        driver.switchTo().newWindow(WindowType.TAB);

        driver.get("https://www.google.com");

        System.out.println("New Tab Title: "
                + driver.getTitle());

        driver.switchTo().window(parentWindow);

        System.out.println("Parent Title: "
                + driver.getTitle());

        driver.quit();
    }
}
```

# 22. close() vs quit()

## close()

Closes the current browser window/tab.

```java
driver.close();
```

## quit()

Closes all browser windows and ends the WebDriver session.

```java
driver.quit();
```

Comparison:

| Method    | Action                                             |
| --------- | -------------------------------------------------- |
| `close()` | Closes current tab/window                          |
| `quit()`  | Closes all tabs/windows and ends WebDriver session |

---

# 23. Important Issue After close()

Suppose:

```text
Parent
Child
```

You switch to Child:

```java
driver.switchTo().window(child);
```

Then:

```java
driver.close();
```

The child tab is closed.

However, Selenium does **not automatically switch back to the parent tab**.

You should explicitly switch:

```java
driver.switchTo().window(parent);
```

Example:

```java
driver.switchTo().window(child);

driver.close();

driver.switchTo().window(parent);
```

# 26. Handling New Tab with Expected Number of Windows

You can wait until a new tab is opened.

Example:

```java
WebDriverWait wait = new WebDriverWait(
        driver,
        Duration.ofSeconds(10)
);

wait.until(driver ->
        driver.getWindowHandles().size() > 1
);
```

Imports:

```java
import java.time.Duration;

import org.openqa.selenium.support.ui.WebDriverWait;
```

Then:

```java
Set<String> windows = driver.getWindowHandles();
```

---

# 27. Complete Example with Explicit Wait

```java
import java.time.Duration;
import java.util.Set;

import org.openqa.selenium.WebDriver;
import org.openqa.selenium.chrome.ChromeDriver;
import org.openqa.selenium.support.ui.WebDriverWait;

public class MultipleTabs {

    public static void main(String[] args) {

        WebDriver driver = new ChromeDriver();

        driver.get("https://example.com");

        String parent = driver.getWindowHandle();

        driver.switchTo().newWindow(WindowType.TAB);

        driver.get("https://www.google.com");

        WebDriverWait wait =
                new WebDriverWait(driver, Duration.ofSeconds(10));

        wait.until(d -> d.getWindowHandles().size() > 1);

        Set<String> windows = driver.getWindowHandles();

        for (String window : windows) {

            driver.switchTo().window(window);

            System.out.println("Title: " +
                    driver.getTitle());
        }

        driver.switchTo().window(parent);

        driver.quit();
    }
}
```

# 28. Common Real-World Pattern

A very common automation pattern is:

```java
String parentWindow = driver.getWindowHandle();

Set<String> allWindows = driver.getWindowHandles();

for (String window : allWindows) {

    if (!window.equals(parentWindow)) {

        driver.switchTo().window(window);

        // Perform child-tab operations

        driver.close();
    }
}

driver.switchTo().window(parentWindow);
```

Remember this pattern for interviews and automation projects.

# 29. Common Exceptions

## NoSuchWindowException

Occurs when Selenium attempts to interact with a window that no longer exists.

Example:

```java
driver.switchTo().window(closedWindow);
```

Possible reasons:

* Window was already closed
* Invalid window handle
* Browser crashed
* Window disappeared unexpectedly

---

## StaleElementReferenceException

This can occur when the page/tab changes and a previously located element is no longer attached to the DOM.

Example:

```java
WebElement element = driver.findElement(By.id("test"));

driver.switchTo().window(child);

element.click();
```

The element may no longer belong to the currently active page.

Solution:

Locate the element again after switching:

```java
driver.switchTo().window(child);

WebElement element =
        driver.findElement(By.id("test"));

element.click();
```

---

# 30. Common Mistake: Forgetting to Switch

Incorrect:

```java
driver.findElement(By.id("childElement")).click();
```

if the element exists in another tab.

Correct:

```java
driver.switchTo().window(childWindow);

driver.findElement(By.id("childElement")).click();
```

---

# 31. Common Mistake: Assuming Window Order

Avoid relying heavily on:

```java
windows.get(1);
```

because the order of window handles should not be treated as a reliable business identifier.

Better:

```java
for (String window : driver.getWindowHandles()) {

    driver.switchTo().window(window);

    if (driver.getTitle().contains("Google")) {
        break;
    }
}
```

---

# 32. Common Mistake: Using close() Instead of quit()

Incorrect cleanup:

```java
driver.close();
```

when the intention is to end the entire test.

Better:

```java
driver.quit();
```

Use:

```java
close()
```

when you intentionally want to close only the current tab/window.

Use:

```java
quit()
```

when the test is finished.

# 33. Tabs vs Windows vs Frames

These concepts are different.

### Tabs/Windows

Use:

```java
driver.switchTo().window(handle);
```

### Frames

Use:

```java
driver.switchTo().frame(frameElement);
```

### Parent Frame

Use:

```java
driver.switchTo().parentFrame();
```

### Main Page

Use:

```java
driver.switchTo().defaultContent();
```

Do not confuse window handles with frame switching.

# 47. Key Takeaway

The most important concept is:

```java
driver.switchTo().window(windowHandle);
```

Selenium uses **window handles** to identify browser tabs and windows.

The basic workflow is:

```text
1. Store parent handle
       ↓
2. Open/cause child tab
       ↓
3. Get all window handles
       ↓
4. Find child handle
       ↓
5. Switch to child
       ↓
6. Perform actions
       ↓
7. Close child if required
       ↓
8. Switch back to parent
```

Core APIs:

```java
getWindowHandle()
getWindowHandles()
switchTo().window()
switchTo().newWindow(WindowType.TAB)
switchTo().newWindow(WindowType.WINDOW)
close()
quit()
```
