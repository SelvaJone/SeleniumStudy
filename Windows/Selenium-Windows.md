# Selenium Windows Handling

## 1. Introduction

In Selenium, browser windows and tabs are handled using **window handles**.

A browser window or tab has a unique identifier called a **Window Handle**.

Selenium provides methods through `WebDriver` to:

* Get the current window handle
* Get all open window handles
* Switch from one window/tab to another
* Close the current window
* Return to the parent window

---

## 2. Important Methods

| Method                      | Description                                               |
| --------------------------- | --------------------------------------------------------- |
| `getWindowHandle()`         | Returns the handle of the current window                  |
| `getWindowHandles()`        | Returns handles of all open windows/tabs                  |
| `switchTo().window(handle)` | Switches to a specific window                             |
| `close()`                   | Closes the current window                                 |
| `quit()`                    | Closes all browser windows and ends the WebDriver session |

---

## 3. `getWindowHandle()`

Returns the unique ID of the currently active browser window.

```java
String parentWindow = driver.getWindowHandle();

System.out.println(parentWindow);
```

Example output:

```text
CDwindow-8A7F123456789
```

The actual value is generated by the browser and will be different each time.

---

## 4. `getWindowHandles()`

Returns the handles of **all currently open windows/tabs**.

```java
Set<String> allWindows = driver.getWindowHandles();

System.out.println(allWindows);
```

Because the return type is `Set<String>`, import:

```java
import java.util.Set;
```

---

## 5. Basic Parent and Child Window Example

Suppose clicking a button opens a new tab.

```java
String parentWindow = driver.getWindowHandle();

driver.findElement(By.id("openWindow")).click();

Set<String> allWindows = driver.getWindowHandles();

for (String window : allWindows) {

    if (!window.equals(parentWindow)) {
        driver.switchTo().window(window);
        break;
    }
}
```

Now Selenium is switched to the child window.

---

## 6. Complete Example

```java
import java.util.Set;

import org.openqa.selenium.By;
import org.openqa.selenium.WebDriver;
import org.openqa.selenium.chrome.ChromeDriver;

public class WindowHandling {

    public static void main(String[] args) {

        WebDriver driver = new ChromeDriver();

        driver.manage().window().maximize();

        driver.get("https://example.com");

        // Store parent window
        String parentWindow = driver.getWindowHandle();

        // Open child window
        driver.findElement(By.id("openWindow")).click();

        // Get all windows
        Set<String> allWindows = driver.getWindowHandles();

        // Switch to child window
        for (String window : allWindows) {

            if (!window.equals(parentWindow)) {
                driver.switchTo().window(window);
                break;
            }
        }

        System.out.println("Current Window: " + driver.getTitle());

        // Close child window
        driver.close();

        // Switch back to parent
        driver.switchTo().window(parentWindow);

        System.out.println("Parent Window: " + driver.getTitle());

        driver.quit();
    }
}
```

# 11. Switching by Window Title

Sometimes we don't want to depend on the order of window handles.

We can switch based on the window title.

```java
Set<String> windows = driver.getWindowHandles();

for (String window : windows) {

    driver.switchTo().window(window);

    if (driver.getTitle().equals("Child Window Title")) {
        break;
    }
}
```

This is useful when multiple windows are open.

# 13. Switching to a Specific Window by Title

Create a reusable utility method:

```java
public static void switchToWindowByTitle(
        WebDriver driver,
        String expectedTitle) {

    Set<String> windows = driver.getWindowHandles();

    for (String window : windows) {

        driver.switchTo().window(window);

        if (driver.getTitle().equals(expectedTitle)) {
            return;
        }
    }

    throw new RuntimeException(
            "Window with title not found: " + expectedTitle);
}
```

Usage:

```java
switchToWindowByTitle(driver, "Payment Page");
```

# 15. Closing a Child Window

`close()` closes only the currently active window.

```java
driver.close();
```

Example:

```java
driver.switchTo().window(childWindow);

driver.close();

driver.switchTo().window(parentWindow);
```

Important:

```java
close()
```

does **not** close the entire WebDriver session.

---

# 16. `close()` vs `quit()`

### `close()`

Closes the current browser window/tab.

```java
driver.close();
```

### `quit()`

Closes all browser windows and terminates the WebDriver session.

```java
driver.quit();
```

### Difference

```text
driver.close()
     ↓
Closes current window only

driver.quit()
     ↓
Closes all windows
     ↓
Ends WebDriver session
```

# 17. Important Error After Closing a Window

Consider:

```java
driver.close();

driver.findElement(By.id("username")).sendKeys("Selva");
```

This may cause:

```text
NoSuchWindowException
```

because Selenium is still referring to a window that has already been closed.

Correct approach:

```java
driver.close();

driver.switchTo().window(parentWindow);

driver.findElement(By.id("username")).sendKeys("Selva");
```

# 33. Window Handling with Explicit Wait

Sometimes a child window takes time to open.

Instead of immediately calling:

```java
driver.getWindowHandles();
```

we can wait until the required number of windows is available.

```java
WebDriverWait wait = new WebDriverWait(
        driver,
        Duration.ofSeconds(10)
);

wait.until(ExpectedConditions.numberOfWindowsToBe(2));
```

Imports:

```java
import java.time.Duration;

import org.openqa.selenium.support.ui.ExpectedConditions;
import org.openqa.selenium.support.ui.WebDriverWait;
```

Then:

```java
Set<String> windows = driver.getWindowHandles();
```

---

# 38. Common Exceptions

## NoSuchWindowException

Occurs when Selenium tries to interact with a window that doesn't exist or has already been closed.

```java
driver.close();

driver.findElement(By.id("test")).click();
```

Possible result:

```text
NoSuchWindowException
```

---

## NoSuchElementException

This is different from `NoSuchWindowException`.

It usually occurs when Selenium cannot find an element in the **current window/page**.

Example:

```java
driver.findElement(By.id("username"));
```

If the element exists in another window, switch first:

```java
driver.switchTo().window(childWindow);

driver.findElement(By.id("username"));
```

---

# 39. Important Difference: Window Handle vs Window ID

Selenium uses a **window handle** to identify browser windows/tabs.

```java
String window = driver.getWindowHandle();
```

Window handles are:

* Unique within the WebDriver session
* Used to switch between windows
* Returned as `String`
* Not the browser's visible window title

---

# 40. Window Handle Is Not the Window Title

This:

```java
driver.getWindowHandle();
```

returns an identifier.

This:

```java
driver.getTitle();
```

returns the page title.

Example:

```java
String handle = driver.getWindowHandle();

String title = driver.getTitle();

System.out.println(handle);
System.out.println(title);
```

---

# 41. Window Handle Is Not the URL

These are different:

```java
driver.getWindowHandle();
```

```java
driver.getCurrentUrl();
```

The first identifies the browser window.

The second returns the current page URL.

# 42. Best Practices

### 1. Always store the parent handle

```java
String parent = driver.getWindowHandle();
```

### 2. Use `getWindowHandles()` for multiple windows

```java
Set<String> windows = driver.getWindowHandles();
```

### 3. Switch before interacting with elements

```java
driver.switchTo().window(child);
```

### 4. Close only the required child window

```java
driver.close();
```

### 5. Return to parent after closing child

```java
driver.switchTo().window(parent);
```

### 6. Use explicit waits when windows open asynchronously

```java
wait.until(
    ExpectedConditions.numberOfWindowsToBe(2)
);
```

### 7. Use `quit()` at the end of the test

```java
driver.quit();
```

# 46. Key Points to Remember

```text
getWindowHandle()
        ↓
Current window

getWindowHandles()
        ↓
All windows/tabs

switchTo().window(handle)
        ↓
Switch window

close()
        ↓
Close current window

quit()
        ↓
Close all windows + end session

newWindow(WindowType.TAB)
        ↓
Create new tab

newWindow(WindowType.WINDOW)

```

**Golden Rule:**

> Selenium can only interact with elements in the currently active window/tab. Always switch to the required window before locating or interacting with its elements.
