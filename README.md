# Selenium Study

A structured personal knowledge base for learning and practicing **Selenium WebDriver** with Java/Python.
This repo is organized by topic so concepts can be reviewed independently.

## 📁 Folder Structure

| Folder | Description |
|---|---|
| `Selenium-Basics` | Introduction to Selenium, setup, and first scripts |
| `WebDriver` | WebDriver interface, browser drivers, and lifecycle |
| `Browser` | Browser navigation, window/tab handling, and management |
| `Locators` | Locating strategies (ID, XPath, CSS Selector, etc.) |
| `WebElements` | Working with WebElement methods and interactions |
| `Waits` | Implicit, explicit, and fluent waits |

## 🎯 Purpose

- Document Selenium concepts as I learn them
- Keep reusable code snippets and examples
- Track best practices and common pitfalls

## 🛠 Tech Stack

- Selenium WebDriver
- Java / Python (update based on your language)
- Maven / PyTest (update based on your tooling)

## 📌 How to Use

Each folder contains a `README.md` explaining the topic, along with example code files.
